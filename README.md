# 🎓 Student Management System

A simple and user-friendly **Student Management System** developed using **HTML, CSS, and JavaScript**.

This project helps to manage student records easily through a simple web interface.

## 📌 Features

* 🏠 Dashboard
* 👨‍🎓 Add Student
* 📋 View Student Records
* 🔍 Search Students
* ✏️ Edit Student Details
* 🗑️ Delete Student Details
* 📊 Display Total Students
* 🏫 Display Departments
* 💾 Store student data using Browser Local Storage
* 📱 Responsive and simple design

## 🛠️ Technologies Used

* **HTML** – Used to create the webpage structure
* **CSS** – Used to design and style the webpage
* **JavaScript** – Used to add functionality and CRUD operations
* **Local Storage** – Used to save student records in the browser

## 📂 Project Structure

```text
Student-Management-System/
│
└── index.html
```

The complete project is created in a single HTML file containing HTML, CSS, and JavaScript.

## 👨‍🎓 Student Details

The system stores the following information:

* Student Name
* Roll Number
* Department
* Email

## ⚙️ CRUD Operations

The project supports basic CRUD operations:

* **Create** – Add a new student
* **Read** – View student records
* **Update** – Edit student information
* **Delete** – Remove student information

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click the file.
5. Select **Open with Live Server**.

You can also open `index.html` directly in a web browser.

## 💾 Data Storage

Student information is stored using **Browser Local Storage**.

This means the student records remain available even after refreshing the webpage on the same browser.

## 🎯 Purpose

The main purpose of this project is to provide a simple system for managing student information and to demonstrate basic **web development and CRUD concepts**.
